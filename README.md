
# 📊 India Census 2011 - Population & Literacy Analysis

## 🔹 Project Overview
This project analyzes the **India Census 2011 dataset** to study population distribution, sex ratio, and literacy.  
It also uses **Machine Learning (Linear Regression)** to predict literacy based on population statistics.

## 🔹 Steps Performed
1. Data exploration & cleaning  
2. Visualizations (Top/least populated states, district-level distribution, etc.)  
3. ML Model (Linear Regression → R² ≈ 0.94)  
4. Key insights & conclusion  

## 🔹 Tools Used
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  

## 🔹 Results
- Uttar Pradesh, Maharashtra, Bihar are most populated states  
- Clear correlation between population & literacy  
- ML model achieved **94% accuracy (R²)**
